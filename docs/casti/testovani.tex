\section{Testování}

\begin{itemize}
  \item \textbf{Jednotkové testy}: ověřují jednotlivé moduly, odděleně od odstatních.
  \item \textbf{Systémové testy}: překládají celé programy IFJ26 a kontrolují návratový kód, výstup a diagnostiku. Při plném běhu se po úspěšném překladu ověří i návratový kód a výstup interpretu \texttt{ic26int}.
  \item \textbf{GitHub Actions}: spouští sestavení, kontrolu formátování, jednotkové a systémové testy.
\end{itemize}
